Loop One

Each video repeats until you push the stick right, then the next one starts. Videos play from the headset’s storage, so nothing streams.

Playlist

In the file picker, open Internal storage, then Download. Long-press to select several. Videos play in filename order, so prefix names with 01, 02 to set it.
